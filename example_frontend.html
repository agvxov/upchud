Upchud a file

You may upload files using the above form or the following command:
curl --upload-file 'MUH.FILE' HOST
NOTE: Files are probably going to be purged after a while, this is most definetly not AnyDrive.

Upchud is a FOSS file uploader service, originally developed for https://up.chud.cyou/

You may find the source code here: https://git.xolatile.top/anon/upchud
